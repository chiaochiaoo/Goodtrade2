# Goodtrade2

A trading algorithm management system (AMS) for managing and deploying trading strategies.

## Dashboard Navigation

The dashboard uses a **tabbed navigation system** located at the top of the dashboard panel. Click on the tab labels to navigate between different sections:

- **Risk** - Risk management and monitoring
- **Gateways** - Market connections and gateway status
- **Symbol** - Symbol-specific trading information
- **Algos** - Algorithm deployment and management  
- **PitchPit** - Market visualization and charts

For detailed information about the dashboard navigation structure, see [DASHBOARD_NAVIGATION.md](DASHBOARD_NAVIGATION.md).
